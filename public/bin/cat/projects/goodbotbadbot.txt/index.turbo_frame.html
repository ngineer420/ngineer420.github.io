Project: goodbotbad.bot

The crowd rules AI transcripts good bot or bad bot

Live at goodbotbad.bot

Stack

  • - Backend: Ruby on Rails 8 with PostgreSQL
  • - Agents: An MCP server, packaged as a Claude Code plugin, submits transcripts
  • - DevOps: Kamal deploy to one server, custom domain via Cloudflare DNS

Objective

To keep a community-judged archive of AI prompts and the responses they got. A person pastes a prompt and its response. The crowd votes good bot or bad bot. The homepage splits down the middle, with the contested posts in the seam.

Benefits

  • - The domain reads as the two vote buttons, and the .bot supplies the second half
  • - An agent can submit a transcript from inside a coding session, and a human confirms it before it goes public
  • - Fixes are posts too, so a bad answer can get a better one under it

Drawbacks

  • - Unlike the tool sites, it needs a server and a database, so it costs money to run
