Project: fontloom.com

A free fancy text generator: type plain text, get 29 stylized Unicode versions of it

Stack

  • - HTML/CSS/JS: Vanilla, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (fontloom.com)

Objective

To turn plain typed text into bold, italic, script, gothic/fraktur, double-struck, bubble/circled, squared, small caps, superscript/subscript, strikethrough, upside-down, mirrored, and zalgo/glitch versions instantly, each with a one-click Copy button — using nothing but Unicode code points, no font files required.

Benefits

  • - Runs entirely client-side; nothing typed is ever sent to a server
  • - No font files bundled — every style is a lookup table into existing Unicode blocks
  • - Missing glyphs (e.g. subscript/superscript gaps, small caps q/x) fall back to the plain character instead of breaking
  • - No backend or database, so the whole site is free to host

Drawbacks

  • - Styled Unicode isn't real bold/italic — some fonts or platforms render certain code points inconsistently or not at all
