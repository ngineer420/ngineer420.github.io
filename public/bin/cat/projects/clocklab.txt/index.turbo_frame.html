Project: Clock Lab

Countdown timers, a stopwatch, pomodoro, alarms, an interval timer and a world clock — all in one tab.

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (clocklab.net)

Objective

To collect the time tools you keep googling — countdown, stopwatch, pomodoro, alarm, interval timer, world clock — behind one fast hub that runs entirely in the browser.

Benefits

  • - Everything runs in the tab; nothing to install
  • - Audible alerts via the Web Audio API
  • - Deep-linkable timers you can bookmark
  • - No account, no ads-first clutter

Drawbacks

  • - A timer can drift or pause if the operating system fully suspends the tab

Easter Eggs

  • - eRabb.it, tucked into the very bottom-right corner of the page
