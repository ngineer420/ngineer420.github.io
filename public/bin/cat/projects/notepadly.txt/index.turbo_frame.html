Project: Notepadly

A distraction-free online notepad that autosaves to your browser, with a markdown mode and a live word count.

Live at notepadly.app

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (notepadly.app)

Objective

To be the notepad you open in a new tab and just start typing in — autosaving locally, offering a markdown preview and word count, and never asking you to sign in.

Benefits

  • - Autosaves to localStorage on every keystroke
  • - Nothing you type is ever sent to a server
  • - Markdown mode with live preview for quick formatting
  • - Loads instantly and works offline

Drawbacks

  • - Notes are tied to one browser — there is no cross-device sync
