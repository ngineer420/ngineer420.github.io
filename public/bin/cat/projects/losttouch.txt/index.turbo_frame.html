Project: losttou.ch

Guides on reconnecting with people you lost touch with

Live at losttou.ch

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain via Cloudflare DNS

Objective

To give a person one calm place to read before they send the first message in years: how to reconnect with an old friend, how to apologize for going quiet, and how to keep the memories that started it.

Benefits

  • - Long-form guides with no sign-up and no paywall
  • - One small script adds affiliate tags, and the site works without it
  • - No backend or database, so the whole site is free to host

Drawbacks

  • - With no build step, a change to shared markup means a change to every page

Easter Eggs

  • - eRabb.it, tucked into the very bottom-right corner of the page
