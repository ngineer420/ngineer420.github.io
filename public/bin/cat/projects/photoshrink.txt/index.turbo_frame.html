Project: Photo Shrink

A browser-only toolkit for resizing, compressing, cropping and converting images — nothing is ever uploaded.

Live at photoshrink.net

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (photoshrink.net)

Objective

To bundle the everyday image chores — resize, compress, crop, convert between PNG/JPG/WebP, rotate, image-to-Base64 and favicon generation — into one hub where every pixel is processed on the Canvas API in your own tab.

Benefits

  • - Every image is processed client-side; the file never leaves your device or touches a server
  • - No upload/download round-trip, so even large photos are instant
  • - Convert, compress and crop without installing anything or creating an account
  • - The privacy story is real, not marketing — it works fully offline

Drawbacks

  • - Very large images are bounded by the browser's memory, not a beefy server
