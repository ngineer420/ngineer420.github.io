Project: growingmj.com

Indoor growing and hydroponics guides

Live at growingmj.com

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain via Cloudflare DNS

Objective

To explain an indoor grow as four control loops (light in, water through, air through, and salt in solution) and to pair each loop with a calculator that gives the reader its number.

Benefits

  • - Every guide is one self-contained HTML file, so pages load fast
  • - The VPD, DLI, PPM/EC and fan calculators run in the browser
  • - No account, no cookies of its own, no data sent to a server
  • - No backend or database, so the whole site is free to host

Drawbacks

  • - With no build step, a change to shared markup means a change to every page
