Project: devboxkit.com

Five everyday developer tools in one page: format and validate JSON, encode/decode Base64 and URLs, convert Unix timestamps, and test regular expressions.

Live at devboxkit.com

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (devboxkit.com)

Objective

To collect the small formatting and conversion tools developers reach for all day — JSON, Base64, URL, timestamps, regex — behind one fast page that never uploads your data.

Benefits

  • - Everything runs client-side; nothing you paste is sent anywhere
  • - Five tools without hunting across five different sites
  • - Live JSON validation and regex matching as you type
  • - No account, no ads-first clutter

Drawbacks

  • - Aimed at common cases; not a full IDE or language-aware linter

Easter Eggs

  • - eRabb.it, tucked into the very bottom-right corner of the page
