Project: stickdriftcheck.com

A controller stick drift test: plug in an Xbox, PS5, Switch Pro or any gamepad and instantly check both analog sticks for drift, plus dead zones, buttons, triggers and rumble.

Live at stickdriftcheck.com

Stack

  • - HTML/CSS/JS: Plain, no framework or build step (Gamepad API)
  • - DevOps: Static files on GitHub Pages, custom domain (stickdriftcheck.com)

Objective

To help players diagnose controller stick drift and check every input in the browser before deciding to repair or replace a gamepad.

Benefits

  • - Reads the controller directly via the Gamepad API; nothing is uploaded
  • - Visualises both sticks, dead zones, buttons, triggers and rumble
  • - Works with Xbox, PS5, Switch Pro and generic gamepads
  • - No download and no sign-up

Drawbacks

  • - Limited to controllers the browser's Gamepad API recognises
