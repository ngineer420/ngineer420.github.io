Project: Hue Shift

A set of color tools for designers and developers — a picker, format converters, gradient and palette generators, and a WCAG contrast checker.

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (hueshift.net)

Objective

To give designers and front-end developers a fast, colorful home for picking colors, converting between HEX/RGB/HSL, building gradients and palettes, checking contrast, and pulling a palette out of an uploaded image.

Benefits

  • - Instant, client-side; copy-ready CSS for every result
  • - The interface is the demo — color is used everywhere, on purpose
  • - Contrast checker flags accessibility failures against WCAG AA/AAA
  • - Extract-from-image runs on Canvas, so the picture stays on your device

Drawbacks

  • - Palettes live in the browser only — there is no account to sync them across devices

Easter Eggs

  • - eRabb.it, tucked into the very bottom-right corner of the page
