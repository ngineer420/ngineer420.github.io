Project: chimpmemory.com

The Chimp Memory Test — the working-memory game chimpanzees famously beat humans at — plus Sequence, Number, Visual and Verbal memory tests.

Live at chimpmemory.com

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (chimpmemory.com)

Objective

To turn the well-known working-memory experiments into a set of quick, playable browser tests anyone can try in a minute.

Benefits

  • - Five memory games in one place — Chimp, Sequence, Number, Visual, Verbal
  • - Instant to start; no download and no sign-up
  • - Runs entirely in the browser
  • - No account, no limits

Drawbacks

  • - A casual benchmark for fun, not a clinical cognitive assessment
