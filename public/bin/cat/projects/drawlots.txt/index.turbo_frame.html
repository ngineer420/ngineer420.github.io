Project: Draw Lots

A grab-bag of random-decision tools — a spinner wheel, name picker, dice, coin flip, random numbers and a team generator.

Live at drawlots.net

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (drawlots.net)

Objective

To settle any 'who goes first' or 'pick one' moment with a fair, playful set of randomizers — spin a wheel, pick a name, roll dice, flip a coin, draw a number or split a group into teams.

Benefits

  • - Randomness comes from crypto.getRandomValues, not Math.random
  • - Shareable results and setups via the URL
  • - Tactile, game-like feel that is fun to use on a screen share
  • - Runs entirely client-side

Drawbacks

  • - Fun and fair, but not audited for regulated gambling use
