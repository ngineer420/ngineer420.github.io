Project: QR Mint

A fast QR code generator for links, WiFi, contact cards and plain text, exporting crisp PNG or scalable SVG.

Live at qrmint.net

Stack

  • - HTML/CSS/JS: Plain, no framework or build step
  • - DevOps: Static files on GitHub Pages, custom domain (qrmint.net)

Objective

To generate QR codes for the content people actually need — a URL, WiFi credentials, a vCard contact, or plain text — entirely in the browser, with vector SVG output for print.

Benefits

  • - Codes are generated client-side; your data is never sent anywhere
  • - Download a scalable SVG for print or a PNG for the web
  • - Presets for WiFi and vCard build the right payload for you
  • - No watermark, no sign-up, no limits

Drawbacks

  • - Generation only — scanning/decoding a QR code is out of scope
