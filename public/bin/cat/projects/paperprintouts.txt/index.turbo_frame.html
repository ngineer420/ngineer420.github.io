Project: paperprintouts.com

Nine printable paper and worksheet generators that draw the sheet to your measurements and print it at true physical size — English paper piecing templates, bubble answer sheets, clock faces, blank periodic tables, attendance grids, graph, dot grid and lined paper.

Live at paperprintouts.com

Stack

  • - HTML/CSS/JS: Plain, no framework, no build step for the browser code
  • - Build: A Python generator emits every page twice, as a directory index and a flat alias
  • - DevOps: Static files on GitHub Pages, custom domain (paperprintouts.com)

Objective

Most printable paper online is a fixed PDF. If you need three-quarter inch hexagons and the file is one inch, the file is no use to you. Every generator here draws its sheet from the measurements you give it, in millimetres, so you get the size you actually asked for.

Benefits

  • - Sheets print at true 1:1 scale — a 100 mm square measures 100 mm
  • - Paste a class roster and it prints one named sheet per student in a single job
  • - Nothing you type is uploaded, because there is no server to upload it to
  • - Download SVG for a Cricut or a laser cutter
  • - No watermark, no day pass, no sign-up

Drawbacks

  • - True scale depends on the printer; a dialogue set to "fit to page" quietly shrinks everything, which is why there is a calibration sheet
  • - Print only — the attendance grid cannot add up an attendance rate the way a spreadsheet would

Easter Eggs

  • - The calibration page draws a 100 mm square and a 4 inch square from the same corner, so you can see the 1.6 mm they differ by
