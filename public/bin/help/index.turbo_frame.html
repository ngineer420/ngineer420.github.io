Commands

  • - cat [FILE] — print a file, for example cat projects/reflexzap.txt
  • - cd [DIRECTORY] — change the current directory
  • - clear — clear the screen (or press Cmd+K)
  • - help — print this list
  • - ls [DIRECTORY] — list the files in a directory
  • - pwd — print the current directory
  • - security — open the vault. Say the magic word first
  • - source-control — open the source code of this site on GitHub

Tab completes a command or a path. The up and down arrows walk the command history.
